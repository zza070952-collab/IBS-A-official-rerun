# Code-only publication scope

Prepared on 2026-11-17 for the owner of `zza070952-collab/IBS-A-official-rerun`.

Included: the frozen main GWAS/MAGMA, bulk DESeq2/GSEA/QC, author-compatible spatial preprocessing, official BayesSpace and SpatialDM, continuous evidence/ranking/native-column preservation, computational figure/reporting source, manuscript figure code and required R dependency, actual software records, frozen protocols/ranking rule, checksums and a lightweight view of actual historical outer execution commands.

Original analysis source files retain their exact archived bytes. The source manifest records all byte-preserving copies, gzip decompressions and the reconstructed wrapper. The wrapper's checksum equals the historical server file-manifest checksum. New Markdown, release manifests and `tools/verify_source_manifest.py` are repository-publication materials, not newly executed analysis algorithms.

Excluded: raw data and count matrices, complete SNP GWAS and 1000 Genomes LD distributions, statistical result tables/figures, H5/H5AD/RDS objects and model chains, environments/binaries/caches, SSH helpers/keys, API credentials, private connection configuration, old-project results, local staged/draft duplicates and unused recovery machinery. The complete frozen source archives remain preserved outside this GitHub repository.

This selected core source package does not claim one-command end-to-end reproducibility. All scientific inputs, external software and reference annotations must be obtained under their original terms and verified. Historic project-path checks, gates and checkpoints remain in the source. Ancillary code not preserved in the selected frozen source set is not silently invented.

Only a source-code/file-integrity review was performed for this upload. No GWAS, MAGMA, DESeq2, GSEA, BayesSpace, SpatialDM, ranking, model fitting or wet-lab analysis was rerun. The current server SSH banner did not respond; this publication identifies the frozen delivered archives and does not assert a new live-server snapshot.
